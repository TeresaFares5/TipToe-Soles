Our return promise

TipToe Soles is confident that you will be happy with your purchase. If this is not the case, we offer free returns for items over $60 within 28 days of the order date.

Important: Use registered post when returning an item. TipToe Soles cannot take responsibility for returned items that are not received.

Change-of-mind conditions

To be accepted, a change-of-mind return must meet all four conditions:

  1. The item is returned within 28 days of the order date.
  2. The item is unworn and the original tags remain attached. Shoes with dirty marks or damaged soles cannot be accepted.
  3. The item is returned in its original shoe box and the box remains in its original condition.
  4. Original postage costs are non-refundable.

TipToe Soles reserves the right to refuse a return when these conditions are not met.

Need help?

Contact customer service before returning an item if you are unsure whether it meets the return conditions.
