TIPTOE SOLES WEBSITE - PART 3, TASK 1
=====================================

Open index.html in a web browser to begin. No installation or build step is
required.

Directory structure
-------------------
TipToe Soles/
|-- index.html             Home page
|-- products.html          Full product catalogue and filters
|-- services.html          Customer services page
|-- about.html             About us page
|-- contact.html           Contact us page
|-- search.html            Product search page
|-- login.html             Demonstration login form
|-- wishlist.html          Saved products page
|-- feedback.html          Customer feedback form
|-- returns.html           Returns and exchanges policy
|-- delivery.html          Delivery information
|-- privacy.html           Privacy policy
|-- styles.css             Shared responsive stylesheet
|-- site.js                Shared menu, search, form and wishlist logic
`-- images/                Logo and product images

Assessment features
-------------------
- Twelve functional HTML pages linked through one consistent navigation menu
- Semantic header, navigation, main, section, article, form and footer elements
- Company logo linking to the home page
- Current-page indicators using aria-current and the current-page class
- One shared external stylesheet with no inline or internal styles
- Responsive desktop, tablet and mobile layouts
- Accessible hamburger menu with Escape-key support on smaller screens
- Product search and category filters with a live result count
- Working local wishlist with add, remove, saved-item count and persistence
- Locally validated demonstration login and feedback forms
- Accessible image text, form labels, focus states and skip navigation links

Suggested testing checklist
---------------------------
1. Open index.html and use every main navigation link.
2. Resize below 980px and open and close the hamburger menu.
3. Press Escape while the hamburger menu is open.
4. Add two products to the wishlist and check the navigation count.
5. Open wishlist.html, remove one item and refresh the page.
6. Search for "black" on products.html and check that three shoes remain.
7. Filter products by men's and women's shoes.
8. Submit the login and feedback forms with missing and valid test data.
9. Tab through links, controls and forms to check visible keyboard focus.
10. Check layouts at approximately 390px, 768px and 1280px wide.
