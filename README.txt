TIPTOE SOLES WEBSITE - PART 3, TASK 1
=====================================

Open index.html in a web browser to begin.

Directory structure
-------------------
tiptoe-soles-website/
|-- index.html             Home page
|-- about.html             About us page
|-- contact.html           Contact us page
|-- css/
|   `-- styles.css         One external stylesheet used by every page
`-- images/                Logo and product images

Assessment features
-------------------
- Three functional HTML pages linked through the navigation menu
- Semantic header, navigation, main, section, article, form and footer elements
- Company logo linking to the home page
- Current page indicator using aria-current and a styled current-page class
- One shared external CSS file with no inline or internal styles
- Monochromatic interface colour scheme
- Custom link, visited, hover and keyboard focus styles
- Responsive desktop, tablet and mobile layouts
- Accessible image text, form labels, focus states and skip navigation link
- Utility and social media links in the footer

Screen recording checklist
--------------------------
1. Display an electronic sticky note containing your full name.
2. Open index.html and show the home page.
3. Select About us and Contact us from the navigation.
4. Show the current-page indicator on each page.
5. Hover over navigation, content and footer links to show their styled states.
6. Resize the browser to demonstrate the mobile layout.
7. Use the Tab key to demonstrate keyboard navigation and visible focus.
8. Complete the required contact form fields and show browser validation.

Note: The assessment only requires the Home, About us and Contact us links to
be functional. The remaining navigation and policy links are included to show
the complete structure requested by the client.
